**Status:** Live at https://dgrlabs.co/invaders/ and as claude.ai artifact https://claude.ai/artifact/6oEzjPPfqKYNu5ouRPBu5g (private).

- `invaders.html` is the source and has no document skeleton, because the artifact host adds one. Publish this file to the artifact, passing the artifact URL as `url` (it was first published from the old `index.html` path).
- `index.html` is generated by `build.sh`, never hand-edited. Its copy at `dgrlabs_co/invaders/index.html` must match it byte for byte.
- Publishing order: edit `invaders.html`, run `./build.sh`, copy `index.html` into dgrlabs_co, then commit and push both repos. Republish the artifact.
- `docs/banner.jpg` (README header) and `dgrlabs_co/assets/invaders.jpg` (site card) are headless-Chrome screenshots of the scene; regenerate them if the look changes.
- Headless Chrome barely ticks `requestAnimationFrame` under `--virtual-time-budget`; to smoke-test gameplay, shim rAF with `setTimeout` in a scratch copy.
- Public text (README, site card, in-game copy) follows the workspace no-AI-tells rule.
